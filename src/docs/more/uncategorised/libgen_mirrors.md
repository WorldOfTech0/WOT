# ► LibGen Mirrors

- 📚 **[Library Genesis (.is)](https://libgen.is/)** - Primary gateway mirror for scientific articles and books.
- 🌐 **[Library Genesis (.rs)](https://libgen.rs/)** - Active mirror offering fast downloads of fiction and non-fiction.
- 🖥️ **[Library Genesis (.li)](https://libgen.li/)** - Stable alternate mirror database for search and retrieval.
- [Z-Library](https://z-lib.org/) - One of the largest shadow library databases for books and articles.
