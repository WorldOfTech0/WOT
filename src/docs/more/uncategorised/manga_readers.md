# ► Manga Readers

- 📖 **[Mihon](https://mihon.app/)** - The official successor to Tachiyomi; highly customizable manga reading client.
- 💻 **[YACReader](https://www.yacreader.com/)** - Premium cross-platform comic reader and library manager with beautiful transition layouts.
- 🎨 **[Kavita](https://www.kavitareader.com/)** - Rich, modern, lightning-fast self-hosted server for manga, comics, and books.
- [Komga](https://komga.org/) - Elegant media server for your comics, manga, BDs, and magazines.
