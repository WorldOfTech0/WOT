# ► SVG Icons

- 📐 **[Simple Icons](https://simpleicons.org/)** - Thousands of free SVG icons for popular brands and digital logos.
- ⚡ **[Tabler Icons](https://tabler-icons.io/)** - Over 5,000 highly customizable, clean SVG outline icons for designers.
- 🎨 **[Heroicons](https://heroicons.com/)** - Beautiful, hand-crafted SVG icons by the makers of Tailwind CSS.
- [Lucide Icons](https://lucide.dev/) - Beautiful, consistent, open-source community icon library.
- [SVG Repo](https://www.svgrepo.com/) - Searchable directory of over 300,000 free vector SVG icons.
