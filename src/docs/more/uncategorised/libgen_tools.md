# ► LibGen Tools

- 📥 **[LibGen Desktop](https://github.com/libgenapps/LibGenDesktop)** - Local library manager and offline search browser for Library Genesis databases.
- ⚡ **[libgen-cli](https://github.com/adriano-di-giovanni/libgen-cli)** - Fast and simple command-line interface to search and download books.
- [LibGen Bot](https://github.com/tg-bot/libgen) - Source code for setting up custom Telegram book downloader bots.
