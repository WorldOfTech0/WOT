# ► Manga Downloaders

- 📥 **[HakuNeko](https://hakuneko.app/)** - Multi-platform desktop downloader for manga and anime from various websites.
- ⚡ **[Manga-Downloader CLI](https://github.com/manga-py/manga-py)** - High-speed, extensible Python command-line utility for bulk manga scraping.
- 📱 **[Tachiyomi (Legacy)](https://tachiyomi.org/)** - Famous open-source manga reader application for Android (now Mihon).
- [FMD2](https://github.com/riderkick/FMD2) - Free Manga Downloader 2, an active open-source media scraper.
