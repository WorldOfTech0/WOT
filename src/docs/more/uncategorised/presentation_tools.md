# ► Presentation Tools

- 🖥️ **[Reveal.js](https://revealjs.com/)** - Open-source HTML presentation framework to create stunning fully-featured slides in HTML.
- ⚡ **[Slides.com](https://slides.com/)** - Premium web-based presentation builder powered by reveal.js.
- 🎨 **[Pitch](https://pitch.com/)** - Collaborative presentation software for modern teams with beautiful design templates.
- [Marp](https://marp.app/) - Markdown Presentation Ecosystem, convert markdown into high-fidelity slides.
- [Slidev](https://sli.dev/) - Presentation slides builder designed specifically for developers and geeks.
