# ► Media Database Site Tools

- 🎥 **[Radarr](https://radarr.video/)** - Movie collection manager for Usenet and BitTorrent users, integrated with media databases.
- 📺 **[Sonarr](https://sonarr.tv/)** - TV series database organizer and automated tracking client.
- 🎧 **[Lidarr](https://lidarr.audio/)** - Music collection manager and tracks indexer for audio enthusiasts.
- [Plex Meta Manager](https://metamanager.wiki/) - Python script to automate collection building in Plex using IMDb/TMDb.
