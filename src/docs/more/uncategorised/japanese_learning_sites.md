# ► Japanese Learning Sites

- 🌸 **[Tae Kim's Guide](https://guidetojapanese.org/learn/)** - Extremely detailed, free, and logical guide to Japanese grammar.
- 📚 **[Jisho](https://jisho.org/)** - Powerful, fast Japanese-English online dictionary.
- ⚡ **[Wanikani](https://www.wanikani.com/)** - Premium Kanji and vocabulary learning system based on spaced repetition.
- [AnkiWeb](https://ankiweb.net/) - Powerful flashcard deck tool for vocabulary memorization.
- [Bunpro](https://bunpro.jp/) - Spaced repetition learning tool specifically for Japanese grammar.
