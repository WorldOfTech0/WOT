# ► Self-Hosted Wiki Alts

- 📚 **[BookStack](https://www.bookstackapp.com/)** - Beautiful, easy-to-use self-hosted wiki platform organizing content using a Books, Chapters, and Pages metaphor.
- ⚡ **[Wiki.js](https://js.wiki/)** - Extremely powerful, node-based modern wiki application built with an elegant visual editor.
- 📝 **[Outline](https://www.getoutline.com/)** - Fast, modern team wiki and knowledge base built for developer teams.
- [DokuWiki](https://www.dokuwiki.org/) - Versatile, easy-to-use open-source wiki software that doesn't require a database.
- [TiddlyWiki](https://tiddlywiki.com/) - Non-linear personal web notebook that can be completely self-contained in a single HTML file.
