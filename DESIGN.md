# Project Brief: WorldOfTech (WOT)

## 1. Executive Summary

**WorldOfTech** is a high-fidelity digital ecosystem dedicated to aggregating the world's best **free technology resources**. The platform serves as a centralized, noise-free hub for discovering industrial-grade software, development frameworks, and educational content that is entirely cost-free.

## 2. Product Vision

To democratize access to high-quality technical tools by providing a "Gold Standard" discovery experience. We prioritize speed, visual beauty, and curated utility to eliminate the friction found in traditional search engines.

## 3. Design Identity

- **Aesthetic**: Terminal-Luxury / Modern Minimalism.
- **Color Palette**:
  - **Surface**: Deep Charcoal / Midnight Violet (#15111e)
  - **Primary**: High-Energy Violet (#8b5cf6)
  - **Accent**: Cyan / Electric Blue (#06b6d4)
  - **Contrast**: Pure White (#ffffff) for high legibility.
- **Visual Elements**: Glassmorphism, smooth gradients, micro-animations (Framer Motion), and crisp border-based separation.
- **Typography**: Inter / Outfit for headings and Roboto Mono for technical data.

## 4. Core Features & Modality

### 4.1 Global Intelligent Search

- **Centralized Engine**: Powered by `Fuse.js` for fuzzy matching.
- **Modal First**: A dedicated search modality accessible from anywhere in the app via hotkeys or action buttons.
- **Keyboard Navigation**: Full support for `ArrowUp`, `ArrowDown`, and `Enter` for a power-user experience.

### 4.2 Resource Discovery

- **Hero Entry**: A stunning, animated landing section focused on immediate intent.
- **Category Grid**: A high-impact visual grid showcasing the 13 primary tech verticals.
- **Dynamic Content**: Data-driven subcategories that scale as the free resource ecosystem grows.

### 4.3 Technical Stack

- **Frontend**: React 18+ with TypeScript 5.x.
- **State**: Zustand v5 for lightweight, high-performance global state.
- **Routing**: React Router v7 for seamless client-side navigation.
- **UI**: Chakra UI v3 + Vanilla CSS for maximum styling control.

## 5. Performance & Accessibility

- **Zero-Latency Search**: Instant filtering of the entire resource catalog.
- **SEO Optimized**: Semantic HTML5 and proper meta-tagging for maximum visibility.
- **Responsive**: Fluid layouts that maintain the "Premium" feel across mobile, tablet, and desktop.
